# real-test result and revise

실사용 중 나온 제보를 바탕으로 당일 발견·수정한 항목들을 간단히 기록한다. 기능 하나를 새로 만든 게 아니라 실사용 테스트에서 나온 버그 수정 모음이라, 평소 12절 형식 대신 issue → 해결만 짧게 남긴다.

---

**1. GPS 인증 후 "내 현장 Q&A"에 새 질문이 안 뜸**
- 원인: 질문은 상세페이지에서만 등록 가능한데, LIVE 탭의 `QaSection`은 `GlobalQaList`와 달리 탭이 다시 보일 때 다시 불러오는 장치(`isActive`)가 없었다. 탭이 `IndexedStack`으로 살아있는 구조라 `initState`가 딱 한 번만 돌아 예전 빈 목록이 계속 남음.
- 해결: `qa_section.dart`에 `isActive` 파라미터 + `didUpdateWidget` 재조회 추가. `live_screen.dart`에서 연결하고, HOT SPOTS 왕복(같은 탭 push/pop) 경로도 key를 새로 발급해 갱신되게 함.

**2. 답변 알림에 답변 내용이 그대로 노출됨**
- 원인: `notification.py`가 알림 발췌를 답변 본문에서 뽑고 있었음.
- 해결: 발췌 출처를 답변 본문 → 원 질문 본문으로 교체(`질문 여러 개 중 무엇에 답이 달렸는지 구분`이라는 원래 목적은 유지하면서 답변 내용은 안 보이게 함).

**3. 실시간 알림 모달이 아무 버튼도 안 눌렀는데 저절로 닫힘**
- 원인: `barrierDismissible: false`는 바깥 탭만 막을 뿐, 브라우저 뒤로가기·Esc 같은 시스템 pop은 그대로 통과시켜 모달을 닫아버림.
- 해결: `notification_banner.dart`의 두 다이얼로그를 `PopScope(canPop: false)`로 감싸 버튼("나중에"/"확인하기")으로만 닫히게 함.

**4. (버그 아님, 조사만) 답변 알림이 금방 사라진다는 제보**
- 확인 결과: 알림 수명이 알림 자신이 아니라 연결된 질문의 TTL(2시간)에 묶여 있음 — 질문 등록 1시간 50분 뒤 답변이 달리면 그 알림은 10분만 보임. 014 정책(P24)의 의도된 동작으로, 이미 그 일지 11절에 한계로 기록돼 있었음. 코드 변경 없음.

**5. 앱 안 "한국관광공사" 언급 전부 삭제**
- 대상: 지도 마커 색상 범례 문구, 상세페이지 방문 집중률 배지, `gemini.py`의 AI 브리핑 프롬프트 재료 라벨·폴백 템플릿 문장.
- 코드 주석·README·worklogs는 사용자에게 노출되지 않아 그대로 둠.

**6. 질문/답변/현장 제보 카드 형식 통일**
- 사용자가 레퍼런스(커뮤니티 앱 "실시간 인기글" 카드)를 주고 "작성자(아바타+닉네임)가 위, 본문이 아래, 현장인증 뱃지는 닉네임 옆"으로 통일해달라고 요청.
- 백엔드: `AnswerResponse`에 `gps_verified` 필드 추가(DB 컬럼은 이미 있었음, 조립 지점 3곳만 수정).
- 프론트: 공용 위젯 `lib/widgets/author_header.dart` 신설(아바타-닉네임-뱃지-시간). `qa_section.dart`·`global_qa_list.dart`·상세페이지 현장 제보 카드에 적용. `GlobalQaList`는 기존 `[관광지명]` 태그를 헤더 위에 그대로 유지.
- 질문자에게는 뱃지를 안 붙임 — 질문 등록은 위치 제한이 없어 애초에 인증 개념이 없음(답변자·제보자만 해당).

**7. AuthorHeader 아바타를 기본 이미지로 통일**
- 원인: 처음엔 닉네임 이니셜로 만들었는데, MyPage 프로필 카드가 이미 "닉네임 이니셜 폐기 → `default_profile.png` 고정 이미지" 정책으로 바뀌어 있었음(P41 폐기, 2026-09-17).
- 해결: `AuthorHeader`도 같은 `assets/images/default_profile.png`를 쓰도록 교체해 정책을 맞춤.

**8. MyPage "내가 쓴 질문" 탭의 답변 버블도 형식 통일**
- 원인: 6번 작업 때 놓쳤던 위치 — `my_qna_screen.dart`의 `_buildAnswerBubble`이 옛날 형식(닉네임만, 아바타·뱃지·시간 없음) 그대로였음.
- 해결: 같은 `AuthorHeader`로 교체. 이 화면은 지난 이력을 보여주는 곳이라 시간 표기는 이 화면의 다른 카드와 같은 `Formatters.reportRecency`를 씀.

**9. 로컬 실행 (카카오 로그인 포함)**
- 백엔드(uvicorn, 8000번 포트) + Flutter 웹앱(Chrome, 8080번 포트)을 로컬에서 기동.
- 카카오 로그인은 `.env`의 `KAKAO_JS_KEY`를 그대로 읽어 `flutter run --dart-define=KAKAO_JS_KEY=...`로 넘겨야 동작함 — 이 키는 브라우저 JS에 그대로 노출되는 공개 키라 안전하게 재사용 가능.
- 코드를 고칠 때마다 앱을 완전히 재시작해서 반영(이 세션 환경에서는 `flutter run`에 표준입력을 붙일 수 없어 hot reload 키 입력이 불가능했음 — 다음에도 같은 제약이면 매번 재기동해야 함).

- 백엔드 — 수정한 모듈 `import` 확인으로 문법·참조 오류 없음 확인.
- 자동 테스트 스위트는 돌리지 않음.

## 남은 것
- 답변 알림 TTL이 원 질문에 묶이는 문제(4번)는 정책상 의도된 동작으로 남겨둠 — 바꾸려면 "질문이 만료돼도 그 답변 알림은 얼마나 더 보여줄지" 정책 결정이 먼저 필요함.
